# THNDR AutoPlay (Android)

بوت أندرويد **يلعب THNDR Block لوحده** على موبايلك — يشوف الشاشة، يقرأ اللوحة والقطع الثلاث، يخطّط بأقوى ذكاء اصطناعي، ويسحب القطع بإصبع افتراضي. إنت مش بتلمس أي شيء.

## كيف يعمل
| المرحلة | التقنية |
|---|---|
| رؤية الشاشة | `MediaProjection` + `ImageReader` (لقطة حية للشاشة) |
| قراءة اللوحة | تحليل ألوان: خلفية الخانة `#012F51`، الأزرق `#31AAFF`، الأصفر `#FFA726`، النص الرمادي للخانات المرقمة. كشف مستطيل اللوحة 9×9 تلقائيًا لأي دقة شاشة |
| قراءة القطع | مكوّنات متصلة تحت اللوحة → تجميع لـ 3 خانات → تحويل لأشكال (حجم مكعب الصينية ≈ 45% من خانة اللوحة) |
| الذكاء الاصطناعي | كل 6 ترتيبات × Beam Search (عرض 32) × تقييم: ثقوب، تشتت، صفوف/أعمدة/مربعات 3×3 قريبة من الامتلاء، مساحات 3×3 فاضية، قابلية 9 قطع اختبارية، الخانات المرقمة، نمو المضاعف |
| الحركة | `AccessibilityService.dispatchGesture` سحب (ضغط–تحريك–ثبات–إفلات) |
| المعايرة | بعد كل حركة يقرأ الشاشة ويتحقق أين نزلت القطعة؛ لو انزاحت بخانة يصحّح إزاحة الإصبع تلقائيًا ويحفظها |

يلعب **قطعة واحدة ثم يعيد قراءة الشاشة** (أكثر أمانًا مع أنيميشن المسح) — لحد ما تخلص اللعبة (مافيش قطع/مافيش مكان).

## التثبيت
1. نزّل `THNDR-AutoPlay.apk` من [Releases](../../releases/latest) وثبّته (اسمح بمصادر غير معروفة).
2. افتح التطبيق:
   - **الظهور فوق التطبيقات** → فعّل.
   - **خدمة الوصول** → فعّل "THNDR AutoPlay (الإيماءات)".
3. اضغط **▶ ابدأ** → اسمح بتسجيل الشاشة.
4. افتح لعبة THNDR Block وابدأ جولة.
5. اضغط الزر العائم **▶**. البوت يلعب لوحده. اضغط **■** للإيقاف.

## الإعدادات
- **قوة الذكاء**: سريع / قوي / أقصى (موصى به — ~0.3 ثانية للتخطيط).
- **الانتظار بعد كل حركة**: زوّده لو الأنيميشن طويل (افتراضي 650ms).
- **سرعة السحب**: افتراضي 420ms. لو القطعة ما نزلتش، بطّئه.
- **تصفير المعايرة**: لو غيّرت الموبايل/الدقة.

## ملاحظات مهمة
- ⚠️ استخدام بوت في لعبة بمكافآت قد يخالف شروط THNDR وقد يؤدي لحظر الحساب. المسؤولية على المستخدم.
- التطبيق لا يتصل بالإنترنت ولا يجمع أي بيانات — كل المعالجة على الجهاز.
- تم ضبط الألوان على لقطات شاشة اللعبة الحالية؛ لو غيّرت اللعبة الثيم، قد تحتاج تعديل `ScreenParser.kt`.

## v1.8.0 — وضع Device Relay (لعب آلي كامل) 🔗
- وضع ثالث «البوت عبر Device Relay»: هذا التطبيق يقرأ الشاشة (MediaProjection) ويخطط بالذكاء الاصطناعي (مستوى 4)،
  وتطبيق **Device Relay** (https://github.com/joknok72-ctrl/device-relay) المثبّت على نفس الموبايل ينفّذ السحب عبر
  خدمة الوصول بتاعته (`combo` down→move→wait→up مع fallback إلى `drag`) — لأن سحب خدمة الوصول بتاعته مجرَّب وشغال على الجهاز.
- الإعدادات: رابط السيرفر (افتراضي `https://device-relay.cracknew37.workers.dev`)، توكن الجهاز `dr_...`، Device ID،
  زر «اختبار الاتصال» (يجيب الأجهزة ويكمل الـ ID تلقائيًا) و«سحب تجريبي».
- الحلقة: capture → parse → (اختياري: مراجعة القطع ✓) → plan → لكل قطعة: drag عبر Relay → capture → التحقق من النزول
  → معايرة الإزاحة تلقائيًا لو نزلت مزحزحة بخانة.
- REST المستخدم: `GET /api/devices/:id`, `POST /api/devices/:id/command {"action":{"type":"combo","combo":[...]},"wait":true}`.

## v2.0.0 — «قياس ثم قفل» 🎯 (بديل السحب الأعمى)
- **الفكرة**: اللعبة ترسم القطعة المسحوبة عند (الإصبع + إزاحة ثابتة) وبمقياس ثابت. بدل تخمين الإزاحة أو تصحيحها بعد النزول،
  البوت **يقيسها قبل أي نزول** بإيماءة قياس غير ضارّة: يمسك القطعة → يرفعها فوق وسط اللوحة ويثبّت ~1.3 ث (dwell زيجزاج)
  → يصوّرها وهي مرفوعة عدة مرات (median) → يرجّعها للصينية ويفلتها هناك (لا يوضع شيء).
- ثم كل قطعة = **ضربة واحدة** (`swipe_path` بتوقيت مضبوط): ضغط وثبات 260ms → رفع → انزلاق لنقطة الإصبع = مركز الخانات − الإزاحة
  المقاسة → ثبات 420ms (اللعبة تقفل الظل على الخانة) → إفلات. لا يوجد إصبع معلّق بين طلبات HTTP.
- التحقق بعد النزول: لو نزلت مزحزحة بخانة كاملة يصحّح الإزاحة بنفس المقدار فورًا؛ لو ما نزلتش يعيد القياس. المعايرة محفوظة.
- أُزيل أسلوب «الإصبع المعلّق» (v1.9) والإعدادات اليدوية.

## v1.9.0 — «السحر» ✨: القطع تطير لمكانها بالملي (حلقة مغلقة)
- لا يوجد «سحب» بمعايرة عمياء بعد الآن. الخطوات لكل قطعة عبر Device Relay (إصبع دائم `finger_down/move/up`):
  1. `combo`: ضغط على القطعة → رفعها قليلاً (اللعبة تكبّرها) → انزلاق إلى مكان الهدف التقريبي **والإصبع يبقى نازلًا**.
  2. لقطة شاشة → إيجاد القطعة «الطايرة» (بكسلات مكعبات جديدة مقابل لقطة الأساس) → قياس مركزها الحقيقي مقابل مركز الخانات المطلوبة.
  3. تحريك الإصبع بالفرق بالضبط (`finger_move`) — تتكرر حتى الخطأ < 12% من الخانة (غالبًا 0–1 تعديل) → `finger_up`.
  4. الإزاحة المقاسة تُحفَظ تلقائيًا فتنزل القطع التالية صح من أول مرة؛ والتحقق بعد النزول ينتظر ثبات الأنيميشن بدل تأخير ثابت.
- أُزيلت إعدادات السحب/الأنيميشن/المعايرة من وضع Relay (تظهر فقط للبوت الداخلي القديم).
